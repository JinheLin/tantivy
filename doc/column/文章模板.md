# 文章模板

> 适用版本：tantivy `<commit>`（`YYYY-MM-DD`）  
> 关键词：`xxx` / `yyy` / `zzz`

## TL;DR

- 用 3～5 条要点概括全文（读完这里就能带走关键结论）。

## 背景

- 这个能力/机制要解决什么问题？
- 典型场景是什么？不做会怎样？

## 核心概念

- 列出本文需要建立的概念、术语、对象之间的关系。
- 若有约束（线程、锁、生命周期、原子性），在这里先讲清楚。

## API 用法（面向使用者）

- 给出最小可用示例（可省略无关 schema/字段细节）。
- 如果有可配置项，说明默认值与常见调参方向。

## 源码导读（面向读者/维护者）

- 给出“从哪里读”的路线图：入口类型/trait → 关键流程 → 关键实现。
- 必要时配一张流程图/时序图（可选）。
- 只讲与主题强相关的代码路径，避免铺开太多支线。

## 工程实践

- 性能、资源、稳定性方面的取舍与建议。
- 适合的监控/日志点、常见故障现象与定位思路。

## 常见问题

- Q: ...
- A: ...

## 小结

- 再用 3～5 条 bullet 复述“最重要的东西”。

## 延伸阅读

- 列出相关源码文件、相关章节、相关 PR/issue（如有）。
